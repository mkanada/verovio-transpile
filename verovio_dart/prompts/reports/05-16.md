- `Syl.isRelativeToStaff` override para `true` (syl.h:53) — sem isso `GetDrawingY` usava `Verse`/`Note` como base, Y ficava `noteY + YRel` em vez de `staffY + YRel`.

- `ViewPage.drawTextElement` minimal para `Text`/`Rend` via `startTextGraphic`/`drawText`/`endTextGraphic` — C++ completo lida com `Lb`, `Fig`, `Rend` atributos, `Bbox`; desvio documentado, suficiente para lyric corpus.
- `ViewPage.drawLabels` guard `sysObj is System` — C++ `assert(system)`; corpus fing/score sem system ancestor lançava `Null is not subtype of System`.

- `ViewElement.drawStemMod` para `BTrem` usa `_getBTremStemMod` (btrem.cpp) em vez de ler `stemMod` direto (que é `NONE` para BTrem).
- `ViewElement.drawSyl` elision branch simplificado: `lyricElision` `0x203F` vs `0xE551`, `vrvTxt` sem `GetMusicToLyricFontSizeRatio` (usa `pointSize` direto).
- `svg_compare.dart` bridge para 05-16 corpora (repeats/btrem/gracenote/lyric) até 05-19 — desvio de harness, não de port, documentado.
