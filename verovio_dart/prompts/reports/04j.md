## Desvios do C++ introduzidos

- **Traço de execução (`FunctorBase.executionTrace`/`processDepth` + gravação em
  `Object.process`)**: não existe no C++. Hook opt-in de teste (lista `null` por padrão,
  custo zero), documentado como port-only. Motivo: o C++ garante a ordem pela leitura de
  `page.cpp`; em Dart, sem a asserção, uma ordem trocada vira mistério numérico.
- **Nenhum outro.** A sequência assertada nos testes é a do `page.cpp` com os desvios
  headless **já documentados** em `doc.dart` (AdjustOssiaStaffDef/Artic/NeumeX/AccidX/
  InitProcessingLists/Syl/HarmGrps/Arpeg/Tempo/XOverflow movidos para a fase vertical, que é
  onde este port produz as bboxes/positioners que eles consomem; CalcAlignmentPitchPos/
  CalcLigatureOrNeumePos/CalcLedgerLines reordenados pelo mesmo motivo; a segunda passada de
  `AdjustSlurs` cross-staff e os running elements ainda não portados). O teste fixa essa
  ordem documentada — a lista esperada cita a linha de `page.cpp` de cada functor.

## Achados fora de escopo

1. **`tool/measure_alignment_gaps.dart` está commitado VAZIO (0 bytes) desde a 04-00** — o
   `git show HEAD` confirma que a versão commitada é vazia; não dá para re-medir os números de
   `maxTime = 0` sem reescrevê-lo. Os números "depois" citados acima são os do relatório 04-00.
   Quem reabrir essa medição (05-12) precisa recriar a tool.
2. **`cpp_probe/run.sh` não filtra registros por tarefa** — regerar o fixture de uma tarefa
   antiga com o binário de uma pilha mais recente contamina o fixture com os registros dos
   patches posteriores (comi esse erro duas vezes antes de entender; os fixtures versionados
   ficaram intactos porque a verificação final foi feita com a pilha certa por tarefa).
   Sugestão para o `cpp_probe/README.md`: tornar explícito que `build.sh <id>` + `run.sh <id>`
   são um par indissociável.
3. **`tool/validate_layout.dart` antigo reportava "match (0)" quando os dois lados não
   compartilhavam nenhum id de nota** — inflava a contagem de matches (a baseline de 24/30
   continha alguns). Agora classificado como `no shared ids`; os 176 matches atuais são todos
   com N ≥ 1 notas efetivamente comparadas.
4. 36 arquivos ficam `unavailable` (o C++ não produz timemap — keysig/mdiv/repeatmark e
   fragments sem notas comparáveis). Vale inventariar o motivo por arquivo numa tarefa de
   corpus, se a 05-12 precisar deles.
