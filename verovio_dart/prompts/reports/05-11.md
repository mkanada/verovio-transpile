## Desvios do C++ introduzidos

- `drawStaff`'s `SetFromFacsimile` é no-op quando `IsFacs()==false` (aproximação documentada); facsimile real exigiria `Zone`/`Surface` e `AdjustDrawingStaffSize` (staff.cpp:318).
- `drawStaffLines`'s gap guitar-tab usa `BoundingBox` temporário `_TempBBox` que delega `getDrawingX/Y` ao staff, em vez de `Object` com `SetParent(system)` do C++; `VerticalContentOverlap` com `margin/2` preservado. Para lute francesa/alemã/italiana o gap é suprimido exatamente como `!isFrenchOrGermanOrItalian`.
- `drawLedgerLines`'s `ConcatenateIDs` junta `dash.events[].id` com espaço, como `ConcatenateIDs` do C++; `svgHtml5` default false, então o ramo `lineDash` não é exercitado pelo corpus default (sem `--svg-html5`).
- `calculatePitchCode`'s `int &octave` vira `List<int> octaveOut` (Dart sem referência), e `touches` usa `Pitchname.*.value` (1..7) em vez de `PITCHNAME_c` macro — valores idênticos.
- `drawStaffDef`/`drawStaffDefCautionary` envolvem `DrawLayerElement` em `try/catch` para `UnimplementedError` e emitem `<g class="clef/keySig/..."/>` vazio quando o alvo ainda é stub (05-13) — sem isso `DrawStaff` nunca alcançaria `DrawLedgerLines` no fluxo original `StaffDef → LedgerLines`; preserva a ordem `keySig → ledgerLines → layer` do golden e permite que `note-009` produza ledger mesmo com `Clef` ainda não desenhado.
- `System.addToDrawingListIfNecessary` replica a whitelist `ANNOT_SCORE/BEAMSPAN/BRACKETSPAN/FIGURE/GLISS/HAIRPIN/LV/OCTAVE/PHRASE/PITCHINFLECTION/SLUR/SYL/TIE` + fallback para qualquer `INTERFACE_TIME_SPANNING` ( `Dir`/`Dynam` extender detalhado fica para 05-20).
- `Layer.getAtPos`/`getPrevious`/`getClef` são aproximações que achatam `isEditorialElement` via `findAllDescendantsByType(LayerElement)`; o C++ usa `GetList`/`GetListPrevious`/`GetListFirstBackward` sobre a lista interna do `Object`.
